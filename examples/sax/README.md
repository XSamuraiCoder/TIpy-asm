# SAX for CE in TIpy

A port of SAX-CE's calculator program from C to TIpy: a Cemetech SAX chat
client that talks over USB serial to the SAX-CE bridge (SAX-CE's `web/` folder).
The wire protocol, keys, nickname rules, and the `SAXCFG` settings AppVar are
the same as SAX-CE's, so it works with the same bridge.

```bash
tipy-asm build examples/sax
```

Send `bin/SAXCE.8xp` with LibLoad and the CE C libraries (`USBDRVCE` and
`SRLDRVCE`, from https://tiny.cc/clibs), then run it.

| Key | Action |
| --- | --- |
| letters / numbers | type (green letter labels) |
| `alpha` | cycle letter mode: abc, ABC, 123 |
| `2nd` | show or hide the on-screen keyboard |
| arrows + `enter` | (keyboard shown) pick and press a key |
| `del` | backspace |
| `enter` / `graph` | send |
| up / down | scroll the chat |
| `y=` | next font |
| `mode` | change nickname |
| `clear` | clear the line, or quit when it is empty |

## Fonts

`y=` cycles through the OS font and every font in the `SAXFONT` font pack.
Build that pack with the font converter: uncomment the font asset in
`pyproject.toml` and point it at a `.fnt` or `.convfont` file, or make a pack
of several fonts with `tipy-asm convfont`. SAX-CE looked for any font pack on
the calculator; this port uses `SAXFONT` only.

## How it differs from the C version

- Text is kept as character codes in integer arrays, and every fixed message
  is in `src/tables.py`, generated by `tools/make_tables.py`.
- The chat log keeps the last 16 messages (SAX-CE kept 48), to keep the
  program small.
- The OS font draws in 8-pixel cells, as SAX-CE's monospace GraphX font did.
